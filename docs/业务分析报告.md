## 三、典型案例

1. **春节效应（2026-02-10 前后）**：节前一周茴香单日 +25%、韭黄 +19%，青萝卜、
   扁豆 z-score 超过 3.7 进入价格异常区间；节后（3 月）急跌达 160 次，为全期最高，
   印证"节前冲高、节后回落"的季节规律。
2. **汛期叶菜急跌（2026-08-01~02）**：菠菜 -21.2%、油菜 -18.8%、小白菜 -36.4%、
   苦菊 -16.0%，8 月初连续两日大范围叶菜急跌，与夏季集中上市叠加降雨影响一致。
3. **产地切换伴随涨价（2026-08-11）**：黄瓜当日产地切换（冀→多产地）且 +8.3%，
   产地切换往往伴随货源结构调整，需人工复核报价合理性。
4. **持续高位（2026-08-11）**：豌豆苗、散叶生菜、油麦菜连续 3 天以上 z-score > 2，
   油麦菜 8 月均价 4.75 元/斤创窗口内新高（+30.1%），处于统计意义上的历史高位。

## 四、业务建议

1. **采购端**：把鸡毛菜、蒿子秆、快菜等叶菜列为重点盯盘品种，波动率高于 0.10 时
   建议与产地锁定 1-3 天短约，避免追涨杀跌；
2. **库存端**：急跌（环比 ≤ -12%）品种控制进货量、优先去库存；急涨品种检查库存
   与替代品种（如叶菜替代为根茎菜），不追高囤货；
3. **定价端**：价格异常确认后 1-2 天再调价（排除单日噪音）；对持续高位品种启动
   专项定价评审；
4. **风控端**：产地切换伴随 ≥5% 价格变化时触发人工复核；春节前 2 周、5-8 月汛期
   提高监控频率（建议每日自动告警，见 `scripts/schedule_windows.ps1`）。

## 五、局限与后续方向

**局限**：① 无成交量数据，无法做量价联动判别；② 仅单市场（北京新发地）；
③ 产地为省级简称、部分缺失；④ 约 38 个品种覆盖天数不足 30 天，滚动统计不可用。

**后续方向**：① 对接多市场数据（农业农村部全国批发市场价格信息系统）做横向对比；
② 引入节假日/季节因子（春节、汛期）做同比基准；③ 对接带成交量的数据源恢复
量价联动规则；④ 用 Prophet/STL 等季节性模型替代纯滚动统计，降低误报。
